> パイプライン全体の設計・学習ワークフロー・座標規約は [PIPELINE.md](./PIPELINE.md) を
> 参照してください（以下のColabガイドは旧運用の記録として残しています）。

## 📋 必要なもの

1. **Googleアカウント** - Google Colabを使用するために必要
2. **動画ファイル** - 検出対象の動画（.mp4など）
3. **重みファイル** - YOLO学習済みモデル（`yolo8m_20250510.pt`）

## 📊 処理内容

1. **前処理（tennis.py）**
   - フレーム間の差分を計算
   - ガンマ補正で物体を強調
   - 小さい物体の検出精度を向上

2. **物体検出（YOLO）**
   - 強調動画に対してYOLO検出を実行
   - カスタム学習済みモデルを使用

3. **軌跡トラッキング**
   - 検出物体を追跡してIDを付与
   - 過去の軌跡を線で描画
   - 検出が途切れても自動的にフェードアウト

## ⚙️ カスタマイズ

ノートブック内の以下のパラメータを変更できます：

```python
# track.py の設定
DRAW_TRAJECTORY = True          # 軌跡描画のオン/オフ
MAX_TRAJECTORY_LENGTH = 10      # 軌跡の長さ（フレーム数）
TRAJECTORY_FADE_FRAMES = 15     # 消えるまでの時間
TRAJECTORY_COLOR = (0, 255, 0)  # 軌跡の色（緑）
TRAJECTORY_THICKNESS = 4        # 軌跡の太さ
```

## ❓ トラブルシューティング

### エラー: "Could not open video"
- 動画ファイルが破損していないか確認
- 対応形式（.mp4, .aviなど）か確認

### エラー: "No module named 'ultralytics'"
- ステップ1（環境セットアップ）を実行したか確認
- セルを再実行してみる

### 処理が遅い
- ランタイムをGPUに変更（ステップ2参照）
- 動画を短くカットして試す

### GPU制限に達した
- 翌日まで待つ
- CPUモードで実行（遅いですが動作します）

## 💾 ファイル保存について

Google Colabのファイルは **一時的** です：
- セッション終了後に削除されます
- 結果は必ずダウンロードしてください
- 長期保存にはGoogle Driveマウントを推奨
